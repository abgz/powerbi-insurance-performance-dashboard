Design decisions

  1. One column, in reading order: scope (three slicers in one row), then the four KPIs, then the trend, then the Top 10.
  2. The slicers share one row, so the scope stays visible without pushing the numbers down.
  3. KPI cards are full width and stacked, which makes each number easy to read on a phone, one per question: volume, performance, capacity, quality.
  4. The trend uses columns for APE and a line for target on a secondary axis.
  5. The Top 10 sits last and excludes the blank agent.
  6. Native visuals only, as the brief requires for this page.
To review from the built report
  1. The two trend axes have different ranges (0M to 1M, and 350K to 370K), so the line and columns are not directly comparable. Consider one shared axis starting at zero.
  2. The month axis is not in calendar order. Sort it by month number.
  3. With several years selected, YTD is ambiguous. Decide whether the Year slicer allows one year only.
  4. The four stacked cards push the trend below the first screen. A 2 by 2 grid would bring it up.
  5. Sale Channel is set to one value in the screenshot, so every number on the page reflects that channel only.
